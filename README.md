# Denchiku

Аудиоплеер для рабочего стола GNOME, сфокусированный на управлении медиатекой.
Написан на C с использованием GTK 4, Libadwaita и GStreamer.

## Возможности

- Автоматическое сканирование папки «Музыка» (`~/<Музыка>` из XDG-каталогов)
  с чтением тегов через `GstDiscoverer`.
- Разделы медиатеки: **Медиатека** (Альбомы, Исполнители, Жанры) и **Треки**
  (Все треки, Любимые треки).
- Плейлисты в боковой панели: сканируются из папки «Музыка» и собственной папки
  данных; новый плейлист создаётся кнопкой «+» у подзаголовка «Плейлисты».
- Контекстное меню плейлиста (ПКМ или долгое нажатие): переименование и удаление
  (кроме «Любимых треков»).
- Стандартный плейлист **«Любимые треки»** с сердечком: треки добавляются и
  удаляются из любимых кнопкой-сердечком в строке трека и в плеер-баре, а также
  пунктом «Добавить в любимые» в меню трека.
- Пункт меню трека «Добавить в плейлисты» с выпадающим списком всех плейлистов.
- Режимы отображения: сетка и список, три уровня масштаба обложек.
- Сортировка по названию, исполнителю и году.
- Страница альбома с трек-листом.
- Встроенные обложки извлекаются из тегов и кэшируются на диск.
- Очередь воспроизведения отдельной боковой панелью с перетаскиванием треков.
- Контекстное меню трека: воспроизвести, играть далее, добавить в очередь,
  убрать из очереди, открыть альбом.
- Плеер-бар с обложкой, полосой перемотки, громкостью и размытым фоном;
  полноэкранный плеер в шторке (`AdwBottomSheet`).
- Режимы перемешивания и повтора (выкл. / вся очередь / один трек).
- Адаптивная вёрстка: при узком окне (≤ 650sp) сайдбар сворачивается,
  а плеер-бар переходит в компактный режим.

## Кэш

Данные хранятся в каталоге кэша пользователя:

- `~/.cache/denchiku/library.cache` — список треков (формат GKeyFile);
- `~/.cache/denchiku/covers/` — извлечённые обложки альбомов.

Кэш заполняется при сканировании и читается при следующем запуске для
мгновенного показа медиатеки до завершения фонового сканирования.

Плейлисты хранятся в формате M3U/M3U8:

- `~/.local/share/denchiku/playlists/` — собственные плейлисты, созданные в
  приложении, включая стандартный `favorites.m3u8` («Любимые треки»);
- плейлисты в папке «Музыка» (`~/<Музыка>`, включая вложенные папки) также
  показываются в боковой панели.

## Сборка

### Зависимости

- компилятор с поддержкой C11 (gcc или clang);
- [Meson](https://mesonbuild.com/) и [Ninja](https://ninja-build.org/);
- библиотеки разработки:
  - `libadwaita-1` (тянет GTK 4 и GLib);
  - `gstreamer-1.0`;
  - `gstreamer-pbutils-1.0`;
  - `gdk-pixbuf-2.0`.

Установка зависимостей по дистрибутивам:

```bash
# Fedora
sudo dnf install gcc meson ninja-build \
  libadwaita-devel gstreamer1-devel gstreamer1-plugins-base-devel gdk-pixbuf2-devel

# Debian / Ubuntu
sudo apt install build-essential meson ninja-build \
  libadwaita-1-dev libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgdk-pixbuf-2.0-dev

# Arch Linux
sudo pacman -S gcc meson ninja \
  libadwaita gstreamer gst-plugins-base gdk-pixbuf2

# openSUSE
sudo zypper install gcc meson ninja \
  libadwaita-devel gstreamer-devel gstreamer-plugins-base-devel gdk-pixbuf-devel
```

Для воспроизведения разных форматов установите наборы плагинов GStreamer
(`gst-plugins-good`, `gst-plugins-bad`, `gst-plugins-ugly`, `gst-libav`
или соответствующие пакеты дистрибутива).

### Сборка и запуск

```bash
# Конфигурация проекта
meson setup build

# Сборка
meson compile -C build

# Запуск
./build/denchiku
```

Эквивалентно через Ninja напрямую:

```bash
ninja -C build
./build/denchiku
```

### Установка в систему

```bash
meson setup build --prefix=/usr/local
meson compile -C build
sudo meson install -C build
```

## Горячие клавиши

| Комбинация | Действие              |
|------------|-----------------------|
| `F5`, `Ctrl+R` | Обновить медиатеку |
| `Ctrl+?`   | Комбинации клавиш     |
| `Ctrl+Q`   | Выход                 |

## Структура проекта

```
src/       ядро: плеер (GStreamer), сканер тегов, кэш, модель трека, плейлисты
src/ui/    интерфейс: окно, разделы медиатеки, плейлисты, плеер-бар, очередь, меню трека
meson.build  описание сборки
```
